# ASE-19

## Project Overview

ASE-19 is a collection of small, self-contained learning projects covering **HTML**, **CSS**, **Bootstrap**, and **JavaScript**.

## Folder Structure

The repository is organized by topic. Each task typically lives in its own numbered folder (e.g., `01-...`, `02-...`) and contains an `index.html`/`index.css` pair, with additional `script.js` and assets when needed.
